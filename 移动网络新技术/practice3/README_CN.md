# 练习3：M-ary对称信道（MSC）

## 练习描述

M-ary对称信道（M-ary Symmetric Channel, MSC）对有噪通信信道进行数学建模。在该信道中，每个传输符号以概率 $P_e$ 被破坏。MSC 是二元对称信道（BSC）向 $q$ 元字母表的推广。

信道由两个参数定义：
- **radix**（基数 $q$）：符号字母表大小，有效符号为 $[0, q-1]$ 内的整数。
- **Pe**（$P_e$）：符号错误概率，取值范围 $[0, 1]$。

## 信道行为

对输入向量中的每个符号，独立地进行以下操作：

1. 以概率 $1 - P_e$：符号**原样通过**，不发生改变。
2. 以概率 $P_e$：符号被**破坏**——替换为从 $q-1$ 个错误值中均匀随机选择的一个值。

形式化地，对于输入符号 $x_i$ 和输出符号 $y_i$，转移概率为：

$$P(y_i = v \mid x_i) = \begin{cases} 1 - P_e & \text{若 } v = x_i \\[4pt] \dfrac{P_e}{q-1} & \text{若 } v \neq x_i \end{cases}$$

这种定义保证了信道的**对称性**：对任意 $a \neq b$，混淆 $a \to b$ 的概率等于混淆 $b \to a$ 的概率。

## 代码结构

```
function received_vector = MSC(encoded_vector, radix, Pe)
```

| 模块 | 说明 |
|------|------|
| **输入校验** | 检查 `radix >= 2`、$P_e \in [0,1]$、输入为行向量、符号在 $[0, \text{radix}-1]$ 内。 |
| **错误掩码** | 生成均匀随机数，通过 `rand(1, n) < Pe` 判定每个位置是否出错。 |
| **错误值替换** | 对每个出错位置，使用 `setdiff` 排除正确值后，用 `randi` 从 $q-1$ 个候选值中均匀随机选取替换值。 |
| **输出** | 返回与输入等长的接收向量。 |

## 原理

M-ary对称信道是二元对称信道向非二元字母表的自然推广。其核心特性：

- **无记忆性**：每个符号是否出错相互独立。
- **对称性**：所有错误转移等概率（$P_e / (q-1)$），即对任意 $a \neq b$，$a \to b$ 和 $b \to a$ 的错误概率相同。
- **均匀错误分布**：一旦发生错误，每个错误值的出现概率相等。这在给定 $P_e$ 下最大化熵（最坏情况）。

测试代码中对 MSC 的统计检验验证了三个条件：
1. 所有 $q \times (q-1)$ 种错误转移均被观测到。
2. 总错误概率接近 $P_e$（容差 0.001）。
3. 所有错误类型的概率均等（最大值与最小值之差 < 0.001）。

该信道模型为评估纠错码性能提供了可分析的基准。二维奇欧码在此信道下的表现通过练习4的蒙特卡洛仿真进行研究。
