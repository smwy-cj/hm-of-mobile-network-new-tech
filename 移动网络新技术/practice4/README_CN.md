# 练习4：蒙特卡洛仿真（Monte Carlo Simulation）

## 练习描述

通过蒙特卡洛仿真评估整个二维奇偶编码通信系统的端到端性能。反复模拟"编码 → 信道 → 解码"的完整链路，统计残余错误，从而估计不同信道错误概率 $P_e$ 下解码后的**符号错误率**（Symbol Error Rate, SER）。

## 仿真流程

```
消息生成 → Encoder编码 → MSC信道加噪 → Decoder解码 → 比较统计
```

对每个 $P_e$ 值：
1. 随机生成大量消息向量。
2. 使用练习1的 `Encoder` 进行编码。
3. 将编码向量通过练习3的 `MSC` 信道传输。
4. 使用练习2的 `Decoder` 对接收向量进行解码。
5. 逐符号比较原始消息与解码消息，统计错误数。

每个 $P_e$ 点持续仿真直到累积 **100~1000 个符号错误**，确保统计估计的稳定性（错误数越多，曲线越平滑）。

## 输出文件

仿真生成以下文件：

- `simulation_results.mat`：原始数据（`Pe_values` 和 `ser_results` 数组）。
- `simulation_results.fig` / `simulation_results.png`：**双对数坐标图**，包含：
  - **解码后 SER**（蓝色实线带标记）：纠错后的残余误符号率。
  - **未编码 SER**（红色虚线）：$y = P_e$ 参考线，表示无编码时的误符号率。

## 原理

### 蒙特卡洛方法

蒙特卡洛仿真通过大量随机采样来估计系统的统计性能。对于纠错码而言，理论上可以通过分析码的重量分布来计算精确的错误概率，但对于实际系统，蒙特卡洛仿真更灵活且直观。

### 对数均匀 $P_e$ 间隔

误符号率通常服从幂律关系（$\text{SER} \propto P_e^t$），在双对数坐标下表现为直线。使用 `logspace` 生成对数间隔的 $P_e$ 值，可以在对数坐标下获得均匀分布的数据点，更好地揭示 SER 曲线的规律。其中指数 $t$ 反映了编码的**分集阶数**（即纠错能力）。

### 错误计数终止准则

以固定的**错误数**（而非试验次数）作为终止条件，可以保证不同 $P_e$ 值下估计的相对精度一致。在低 $P_e$ 时，需要更多的试验次数才能找到 100 个错误，但估计质量与高 $P_e$ 时保持一致。

### 编码增益

解码曲线与 $y = x$ 参考线之间的纵向距离即为**编码增益**（Coding Gain），直观展示了二维奇欧码对系统可靠性的提升程度。

### 预期结果

对于 $(R-1) \times (C-1)$ 的二维奇欧码：
- **单个错误可完全纠正** → 在低 $P_e$ 区域，$\text{SER} \propto P_e^2$（需要编码向量中至少 2 个符号同时出错才可能无法纠正）。
- **随着 $P_e$ 增大**，解码器纠正多重错误的能力下降，SER 曲线逐渐靠近未编码参考线。
