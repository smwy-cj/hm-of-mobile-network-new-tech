# 练习2：二维奇欧解码器（Decoder）

## 练习描述

编码向量经过有噪信道传输后，部分符号可能被篡改。解码器的任务是利用二维奇偶校验结构检测并纠正这些错误，恢复出原始消息。

解码器接收以下参数：
- `received_vector`：接收到的（可能被破坏的）编码向量，长度 $R \times C$。
- `radix`、`rows`、`columns`：与编码时相同的参数。

输出为解码后的消息向量，长度为 $(\text{rows}-1) \times (\text{columns}-1)$。

## 解码算法

### 校验子计算

首先将接收向量重构为 $R \times C$ 的矩阵 $E$。对每一行 $i$ 和每一列 $j$，计算**校验子**（Syndrome）：

$$S_r(i) = \sum_{j=1}^{C} E_{i,j} \bmod q, \qquad S_c(j) = \sum_{i=1}^{R} E_{i,j} \bmod q$$

校验子为零表示该校验通过（该行/列未检测到错误），非零则表示至少存在一个错误。

### 迭代纠错策略

解码器依次尝试三种纠错策略，每次纠正后重新计算校验子，直至无法继续纠正。

#### 策略一 —— 精确匹配

若某个位置 $(i, j)$ 满足 $S_r(i) = S_c(j) \neq 0$，则纠正该位置的符号：

$$E_{i,j} \leftarrow (E_{i,j} - S_r(i)) \bmod q$$

此策略可处理**单个错误**（无论发生在数据区还是校验区）以及**位于不同行不同列的两个错误**。

#### 策略二 —— 唯一列法

对每个**数据行** $i$（不含校验行）：若恰好只有一个数据列 $j$ 的列校验子 $S_c(j) \neq 0$，则利用行校验子进行纠正：

$$E_{i,j} \leftarrow (E_{i,j} - S_r(i)) \bmod q$$

此策略处理**多个错误出现在同一列**的情况（如练习中测试13）。

#### 策略三 —— 唯一行法

对每个**数据列** $j$（不含校验列）：若恰好只有一个数据行 $i$ 的行校验子 $S_r(i) \neq 0$，则利用列校验子进行纠正：

$$E_{i,j} \leftarrow (E_{i,j} - S_c(j)) \bmod q$$

此策略处理**多个错误出现在同一行**的情况（如练习中测试16）。

### 终止条件

当一轮完整扫描未做任何纠正，或迭代次数达到 $R \times C$ 上限时，算法终止。最后提取数据子矩阵 $E_{1:R-1, 1:C-1}$ 作为解码输出。

## 代码结构

```
function decoded_vector = Decoder(received_vector, radix, rows, columns)
```

| 模块 | 说明 |
|------|------|
| **输入校验** | 检查 radix、rows、columns 的范围，输入为行向量，长度匹配，符号范围合法。 |
| **矩阵重构** | 将接收向量按列优先顺序还原为 $R \times C$ 矩阵。 |
| **迭代循环** | 重复计算校验子并尝试纠正，直到无法继续。 |
| **策略一** | 搜索行校验子与列校验子相等的任意位置 $(i,j)$。 |
| **策略二** | 对每个数据行，检查是否只有一个数据列存在非零校验子。 |
| **策略三** | 对每个数据列，检查是否只有一个数据行存在非零校验子。 |
| **消息提取** | 从纠正后的矩阵中按列优先顺序提取数据区，输出解码向量。 |

## 原理

二维奇欧码的纠错能力源于行校验和列校验的**交叉验证**机制：

- **单个错误**：错误所在行和列的校验子相等（均为错误值），唯一确定位置和错误幅度。
- **不同行不同列的两个错误**：每个错误各自产生匹配的行-列校验子对，可独立纠正。
- **同一列多个错误**：行校验子给出每行的错误值，列校验子为各错误之和。策略二逐个隔离每行的贡献进行纠正。
- **同一行多个错误**：列校验子给出每列的错误值。策略三逐个隔离每列的贡献。

该算法不能纠正所有错误模式（例如 $2 \times 2$ 矩形错误会产生歧义），但通过三种策略的组合最大化了可纠正范围。
