# 练习1：二维奇欧编码器（Encoder）

## 练习描述

在一个无线通信系统中，消息通过有噪信道在发射机和接收机之间传输。为了保护消息免受信道噪声的破坏，使用二维奇欧编码器（2D Parity Check Encoder）对消息向量进行编码，通过添加行和列的奇偶校验符号来实现冗余保护。

编码器由三个参数控制：
- **radix**（基数 $q$）：符号的取值范围，每个符号为 $[0, q-1]$ 内的整数。
- **rows**（行数 $R$）：扩展后编码矩阵的行数。
- **columns**（列数 $C$）：扩展后编码矩阵的列数。

输入的消息向量长度为 $(R-1) \times (C-1)$。

## 编码流程

### 第一步 —— 重排矩阵

将消息向量重新排列为 $(R-1) \times (C-1)$ 的矩阵。填充顺序为**逐列填充**：从最左侧列开始，从上到下填入，然后移至下一列。

例如：消息 $[0, 1, 1, 0]$，$R=3, C=3$ → $2 \times 2$ 数据矩阵：

```
第1列：0, 1     →    [0, 1]
第2列：1, 0          [1, 0]
```

### 第二步 —— 添加校验位

在数据矩阵的底部增加一行、右侧增加一列，形成 $R \times C$ 的扩展矩阵。新增的校验符号需满足：

- **行校验**：$\sum_{j=1}^{C} E_{i,j} \equiv 0 \pmod{q}$，即每一行的元素之和为 $q$ 的倍数。
- **列校验**：$\sum_{i=1}^{R} E_{i,j} \equiv 0 \pmod{q}$，即每一列的元素之和为 $q$ 的倍数。

右下角的元素同时满足最后一行和最后一列的校验约束。可以证明，当所有数据行和数据列的校验位正确设置后，右下角的元素自动使得最后一列也满足校验。

### 第三步 —— 向量化

将扩展矩阵按逐列读取（每列从上到下，从左到右）转换为长度为 $R \times C$ 的行向量，即编码输出。

## 代码结构

```
function encoded_vector = Encoder(message_vector, radix, rows, columns)
```

| 模块 | 说明 |
|------|------|
| **输入校验** | 检查 `radix >= 2`、`rows >= 2`、`columns >= 2`，消息为行向量且长度等于 `(rows-1)*(columns-1)`，所有符号在 $[0, \text{radix}-1]$ 范围内。错误使用 `NJU:argChk` 标识符抛出。 |
| **重排矩阵** | 将消息向量按列优先顺序填入 `(rows-1) × (columns-1)` 的矩阵中。 |
| **行校验位** | 对每个数据行 $r$，计算 $E_{r,C} = -\sum_{c=1}^{C-1} E_{r,c} \pmod{q}$。 |
| **列校验位** | 对每个数据列 $c$，计算 $E_{R,c} = -\sum_{r=1}^{R-1} E_{r,c} \pmod{q}$。 |
| **右下角校验位** | 根据最后一行数据列校验位之和计算 $E_{R,C}$，满足最后一行校验约束。 |
| **向量化输出** | 将扩展矩阵按列优先顺序读出为行向量。 |

## 原理

二维奇欧码是一种**乘积码**（Product Code），由两个单奇偶校验码（SPC）正交组合而成。它用 $R + C - 1$ 个校验符号保护 $(R-1)(C-1)$ 个数据符号，编码效率为：

$$\text{码率} = \frac{(R-1)(C-1)}{R \cdot C}$$

该编码可以检测任意单个符号错误，结合练习2的解码器还可以纠正单个错误。其纠错能力来源于行校验和列校验的交叉验证——错误所在行和列的交点即为错误位置。
